POCKETPOD V1.1.1 — AERO + MENU FOLLOW MINI PATCH

Built from V1.1 Streaming QoL. This patch retains V1.1's streaming search, stream queue controls, Recently Streamed, artwork/history, local library, and playback features.

Install: back up your repository, extract this ZIP, replace the PocketPod site files, and deploy to GitHub Pages. On iPhone, reopen the site once in Safari after deployment if the Home Screen app has not picked up the new service worker.

Aero is optional: Settings > Theme Studio > Theme Packs. Classic and Modern remain available.
