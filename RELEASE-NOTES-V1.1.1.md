# PocketPod V1.1.1 — Aero + Menu Follow Mini Patch

Built directly on PocketPod V1.1 Streaming QoL. This is an additive patch; it retains V1.1 streaming search, streaming queue actions, Recently Streamed, stream artwork/history, local library, playback, and existing themes.

## Added
- Optional Aero theme pack in Settings → Theme Studio → Theme Packs.
- Frutiger Aero-inspired aqua gradients, glossy glass-like panels, bright cyan selection, and matching wheel/Now Playing styling.
- Selected menu row automatically scrolls into view during click-wheel and keyboard arrow navigation, using smooth scrolling where motion is permitted. Manual touch scrolling remains available.
- Service-worker cache version bumped to ensure the updated shell is installed.

Classic and Modern remain available and unchanged.
